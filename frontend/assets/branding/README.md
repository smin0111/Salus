# SALUS brand mark

`salus-core-flow-icon-source.png` is the canonical source supplied and selected by the project owner. `salus-logo-mark.png` is the production mark with only the fully transparent outer margin removed; the visible pixels, shading, edges, and proportions are retained from the supplied source.

The mark uses two flowing ribbons around a warm core to represent personal context becoming a guided, healthier flow toward the table. Do not redraw the symbol or use a presentation screenshot as a production asset. Generate every favicon, splash, Android launcher, iOS AppIcon, and in-product mark from the canonical source.
