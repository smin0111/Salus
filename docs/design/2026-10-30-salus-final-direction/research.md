# Salus 최종 디자인 근거
검토일: 2026-10-30

공개 웹 화면과 공식 디자인·제품 자료를 검토했다. 아래 적용 방향은 자료를 바탕으로 한 디자인 판단이며, 각 회사가 Salus 디자인을 검증하거나 보증했다는 뜻이 아니다. Instagram은 공식 디자인 글을, Threads는 공식 글과 로그인 전 공개 화면을 참고했다. 로그인 뒤 개인 피드나 비공개 계정은 열람하지 않았다.

## 최종 방향

따뜻한 흰색 바탕, 먹색 글자, 짙은 녹색 행동 버튼을 사용한다. 로고에만 영문 세리프를 쓰고 한글은 산세리프로 통일한다. 사진·음식 그림·음식 모양 장식 없이 입력창, 문서, 기록 예시가 시각적 중심이 된다.

1. 랜딩: 오늘의 한 끼를 찾는 첫 행동과 결과 예시를 함께 제시한다. 아래에는 식사 기록 예시를 두어 서비스의 두 핵심 기능을 연결한다.
2. 로그인: 소셜 로그인·둘러보기·처리방침에 집중한다. 데스크톱의 짧은 기능 소개를 모바일에서는 덜어낸다.
3. 채팅: 대화와 레시피 상세를 분리한다. 모바일에서는 상세 화면으로 전환한다. 미입력 알레르기 상태를 레시피보다 앞에 두고 출처가 없음을 명시한다.
4. 결제: 30일 이용권, 1회 결제, 자동 재결제 없음, 예시 금액을 구분한다. 모바일에서는 긴 비교표보다 주문 조건과 결제 버튼을 먼저 둔다.

## 시각 검수와 구현 경계

- 네 장에서 음식 사진, 음식 모양 일러스트와 대체 장식이 없는 것을 확인했다.
- 로그인·결제 생성 초안의 불필요한 전역 메뉴를 수정했다.
- 채팅 생성 초안에 삽입된 실제 근거가 아닌 검색 사이트 링크를 제거하고 '출처 정보 없음 · 추가 확인 필요'로 수정했다.
- 모두 이미지 시안이며 실행 가능한 화면 또는 전체 상태 명세가 아니다. 서체의 실제 파일·색 대비·터치 영역·스크린리더·키보드·스크롤과 상태 전환은 구현 때 별도 검증이 필요하다.
- 랜딩 모바일에 생성된 하단 앱 메뉴는 실제 구현 시 공개 랜딩과 로그인 후 앱의 구분에 맞게 조정한다.
- 조리 내용·재료량·시간은 디자인 예시이며 검증된 레시피나 의료 조언이 아니다. 출처·알레르기·검증 상태가 불충분할 때는 기존 서버 정책을 따라야 하며, 이미지의 저장 버튼이 검증 우회를 허용하는 것은 아니다.
- 9,900원은 시안 예시 금액이다. 실제 상품 가격·판매 가능 상태·결제 조건은 서버와 운영 상태를 따라야 한다.
- 실제 서비스 코드·테스트는 변경하지 않았고 빌드·동작 테스트도 실행하지 않았다. 이미지 내용과 구성만 시각 검수했다.
