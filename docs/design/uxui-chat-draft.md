# 채팅 화면 시안 (웹 · 앱) — Claude 초안, 2026-10-29

사용자 요청: "일단 하나씩 다시 잡아보자 채팅 버전을 웹 앱보여봐". 시각 언어는 직전 핵심 화면 시안(숲색 #0B3B32, 크림, 테라코타, 큰 한글 타이포)을 따른다. 안전 배너 4상태 매핑은 docs/design/uxui-redesign-draft.md 그대로. 결과물은 시안 이미지(구현 아님).

## 지금 채팅이 가진 기능(ChatScreen.js 근거) — 시안에서 빠뜨리지 않음
- 대화 세션 목록(불러오기·제목 수정·삭제), 새 대화, 응답 중 멈춤.
- 레시피 카드: safetyNotes, sources(primary/reviewed, 링크), 의료 면책.
- 답변 행동: 복사(앱은 공유), 음성 읽기(로그인), 식단에 추가(로그인, 날짜·끼니 선택), 내 레시피 저장(서버 카드 cardId가 있을 때만, 없으면 "저장할 수 없는 레시피").
- 비회원도 채팅 가능(동의 게이트는 로그인 사용자만), 처음 보는 요리 찾기 하루 제한(회원 5, 비회원 3).

## 웹
- W1 첫 화면: 왼쪽 숲색 사이드바(새 대화, 대화 목록 날짜별, 아래 내 기준 요약·계정), 가운데 큰 인사 + 가운데 입력창 + 잠긴 알레르기 칩 + 예시 질문.
- W2 결과: 가운데 대화(사용자 말 → 진행 단계 한 줄 → 대화 속 요약 카드 + 행동 버튼), 오른쪽 레시피 상세 패널(배너 → 건강 주의 → 재료/만드는 법/출처 탭 → 면책, 저장·식단 추가·조리 모드). 후속 요청 생성 중에도 입력창을 유지하고, 빈 입력일 때 전송 버튼을 멈춤으로 바꾼다.

## 앱
- A1 대화 목록(왼쪽에서 밀려 나오는 시트): 새 대화, 날짜별 목록, 길게 눌러 이름 바꾸기·삭제.
- A2 첫 화면: 큰 인사, 잠긴 칩, 예시 질문, 남은 횟수.
- A3 생성 중: 단계 체크리스트(출처 찾기→재료 정리→알레르기 검사→건강 주의) + 멈춤.
- A4 결과: 대화 속 레시피 카드(배너 → 건강 주의 → 요약 → 재료 꼬리표) + 행동 줄(저장·식단·공유·듣기).
- A5 전체 보기: 아래에서 올라오는 시트, 배너·건강 주의 고정 후 탭(재료/만드는 법/출처), 조리 모드.
- A6 비회원 결과: 배너는 항상 확인 필요("내 알레르기 정보가 없어 개인별 확인을 하지 않았어요"), 저장·식단·듣기 대신 "로그인하면 저장할 수 있어요".

## Codex에게 묻는 것
- 기존 기능 중 빠졌거나 오해를 부를 표시가 있는지(특히 멈춤 후 상태, 저장 불가 카드, 비회원).

## 1회차 검토 반영 (ChatScreen.js:816-818, 417-418, 956 확인)
- 생성 중에도 입력창 유지: 빈 입력이면 오른쪽 버튼이 멈춤, 글자를 입력하면 전송(보내면 지금 답을 멈추고 함께 답함). 안내 문구 "보내면 지금 답을 멈추고 새 말과 함께 답해요".
- 멈춘 질문 표시: 사용자 말풍선 아래 "멈춤 · 다음 메시지와 함께 답해요" 꼬리표(현재 코드 문구 유지). 앱 시안에 멈춤 이후 화면(A7)을 추가.
