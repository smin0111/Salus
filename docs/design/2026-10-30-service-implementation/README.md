# 서비스 화면 디자인 적용 · 2026-10-30

## 적용 범위

- 로그인, PLUS 구매와 결제 결과, 새 채팅과 대화, 채팅 기록 서랍, 레시피 상세.
- 식사 기록의 오늘·주간·월간 보기, 내 레시피 목록·상세·작성·수정, 피드 목록·상세·보조 모달.
- 건강 정보 조회·수정, 검진 분석·입력, 계정·닉네임·가입 동의·정책 문서·로딩·404 화면.
- 상단 메뉴: 채팅 / 식사 기록 / 내 레시피 / 건강 정보 / 피드. 햄버거는 채팅 기록을 엽니다.
- 흰 바탕과 차콜 글자, 작은 녹색 강조, 얇은 구분선, 작은 모서리와 단순한 폼을 공통으로 적용했습니다. 다크 테마도 유지합니다.

랜딩 화면과 전용 컴포넌트, 기존 로고 등 보호 파일 17개는 작업 시작 직전 SHA256과 같습니다. 랜딩의 전용 palette와 로고 색상도 유지했습니다. 기존 미커밋 변경을 기준으로 작업했으며, 백엔드·API·운영 설정은 이번 작업에서 수정하지 않았습니다.

## 유지한 동작

인증과 재인증, 동의 버전 확인, 계정 삭제 확인, 피드 활성화 상태, 채팅 요청 취소와 이전 응답 무시, 서버 발급 cardId 저장 제한, 식사·레시피 저장, 서버 결제 금액과 주문 검증을 유지합니다. 실결제와 피드 활성화는 수행하지 않았습니다.

레시피 건강 주의는 요약에도 표시합니다. 상세와 복사에서 건강 주의·출처 검토 상태·의료 면책을 유지하며, 복사에는 안내문·단계별 팁·분량 대체값·열량 기준·난이도도 포함하도록 보완했습니다. 알레르기 판정이나 검진 추천 정책은 변경하지 않았습니다.

브라우저 데이터와 결제 SDK 응답은 `/tmp`의 localhost 전용 합성 fixture를 사용했습니다. 실제 OAuth, 실결제, 운영 API·LLM 연결, 네이티브 iOS/Android 실행은 검증하지 않았습니다. 백엔드 변경이 없어 백엔드 테스트는 실행하지 않았습니다.
