# Salus 작업 중심 재설계
2026-10-30

## 과제
개인 식사·건강 정보와 요리 찾기, 레시피 저장, 날짜별 기록, PLUS 결제를 제공하는 서비스. 음식 사진과 음식 모양 장식은 사용하지 않는다. 기존 초안의 반복적인 홍보 템플릿을 교체한다.

## 화면별 작업
- 요리 찾기: 오늘 저녁의 재료/요리 요청 입력. 입력창 하나, 주요 버튼 하나. 공개 첫 사용 화면과 제품 진입을 겹치게 한다.
- 로그인: 기존 소셜 계정으로 기록을 이어보기. 소개용 분할 영역을 없앤다.
- 레시피: 찾은 요리를 읽고 조리할 정보 확인 후 날짜/끼니를 골라 기록하기. 본문이 주 영역이며 대화는 보조한다.
- 결제: 상품·금액·이용 기간·재결제 조건 확인과 1회 결제. 판매용 비교 그리드를 짧은 주문 문서로 바꾼다.
- 모바일: 위 작업을 한 열과 별도 화면 전환으로 배치한다.

## 시각 기준
흰색 작업면 #FFFFFF, 탐색 영역 #F3F4F3, 글자 #252927, 보조 글자 #626862, 주요 행동/선택 #30543D. 색은 시안의 의도이며 생성 이미지 모든 픽셀에 정확히 적용됐다고 보장하지 않는다.

한글은 SUIT 계열 한 산세리프와 보통/중간 굵기를 기준으로 삼는다. 로고도 소문자 산세리프로 바꾼다. 화면 제목·본문·고정 라벨의 위계를 좁히고, 장식용 세리프·번호·윗제목·반복 카드·그라데이션을 제외한다.

날짜와 끼니는 실제 기록 대상과 연결되는 곳에만 쓴다. 저장 전에는 '추가할 식사'로 구분한다. 읽을 정보와 선택할 정보는 같은 크기의 카드로 쪼개지 않는다.

## 생성 전 비평에 따른 수정
중앙의 빈 검색 화면으로 보일 위험을 줄이기 위해 왼쪽 정렬된 실제 2줄 입력 상태를 사용했다. 레시피 정보가 좁은 옆칸에 몰리지 않게 레시피 본문과 대화의 면적을 뒤집었다. 로그인·결제에 브랜드 홍보 문구를 반복하지 않는다.

## 비용
전통적인 마케팅 랜딩의 설명량과 시각적 장관은 줄어든다. 그 대신 실제 사용을 빠르게 시작하고 결과를 읽을 공간을 확보한다. 이것이 이번 방향의 선택이다.
